Règles de calcul, jusqu'en terminale

Il n'y a pas tant de règles. La difficulté, c'est de choisir laquelle appliquer : développer ou factoriser, réduire au même dénominateur, faire apparaître un 1, un carré, un facteur commun. D'abord les règles, ensuite les gestes d'exercice.

Priorités opératoires

parenthèses → puissances → × et ÷ → + et −
2 + 3 · 42 = 2 + 3 · 16 = 50. À priorité égale, de gauche à droite : 12 ÷ 3 · 2 = 8.
−a2 ≠ (−a)2
La puissance passe avant le signe : −32 = −9, (−3)2 = 9.

Signes ℤ

a − b = a + (−b)
Soustraire, c'est ajouter l'opposé.
(−a) · (−b) = a · b    (−a) · b = −a · b
Multiplier par −1 = demi-tour sur la droite des réels ; deux demi-tours = un tour.
−(a + b − c) = −a − b + c
C'est (−1) · ( … ) distribué terme à terme.

Fractions ℚ

ab = a · kb · k   (k ≠ 0)
Multiplier ou diviser en haut et en bas par le même nombre non nul ne change rien. C'est la seule façon de simplifier.
ac + bc = a + bc    ab + cd = a d + b cb d
On n'additionne que des fractions de même dénominateur : on y ramène d'abord.
ab · cd = a cb d    abcd = ab · dc
Diviser, c'est multiplier par l'inverse.
x + 33 ≠ x + 1    ab + c ≠ ab + ac
On simplifie des facteurs, jamais des termes. Le bas ne se sépare pas.

Puissances

an · am = an+m    anam = an−m    (an)m = an·m
23 · 24 = 27 ; (23)2 = 26.
(a b)n = an bn    a0 = 1    a−n = 1an
Pour a ≠ 0. 10−3 = 0,001.
(a + b)n ≠ an + bn
(2 + 3)2 = 25, 22 + 32 = 13. Voir les identités remarquables.

Racines ℝ

√a b = √a · √b    √ab = √a√b
Pour a, b ≥ 0 (b > 0 en bas). √50 = √25 · 2 = 5√2.
(√a)2 = a    √a2 = |a|
√(−3)2 = 3, pas −3.
√a + b ≠ √a + √b
√9 + 16 = 5, √9 + √16 = 7.

Développer, factoriser ℝ

k · (a + b) = k a + k b
Lu de gauche à droite : développer. De droite à gauche : factoriser. Même égalité.
(a + b)(c + d) = a c + a d + b c + b d
Chaque terme du premier multiplie chaque terme du second : 4 produits.
a x2 + b x + c = a(x − x1)(x − x2)
Si Δ = b2 − 4ac ≥ 0, avec x1,2 = −b ± √Δ2a. Si Δ < 0 : pas de factorisation dans ℝ (mais oui dans ℂ).

Identités remarquables

(a + b)2 = a2 + 2ab + b2
Le double produit 2ab vient des deux termes du milieu, égaux.
(a − b)2 = a2 − 2ab + b2
(−b)2 = +b2.
(a + b)(a − b) = a2 − b2
Les termes du milieu sont opposés et s'annulent.
(a + b)3 = a3 + 3a2b + 3a b2 + b3 terminale
Coefficients 1, 3, 3, 1 : triangle de Pascal. En général : binôme de Newton.
a3 − b3 = (a − b)(a2 + a b + b2) terminale
an − bn se factorise toujours par (a − b).
a2 + b2 = (a + i b)(a − i b) ℂ
Impossible dans ℝ, possible dans ℂ grâce à i2 = −1.

Équations

A = B ⇔ A + c = B + c ⇔ k A = k B   (k ≠ 0)
On fait la même opération des deux côtés. « Passer de l'autre côté » n'est qu'un raccourci.
A · B = 0 ⇔ A = 0 ou B = 0
Produit nul : d'où l'intérêt de factoriser avant de résoudre.
AB = 0 ⇔ A = 0 et B ≠ 0
Toujours vérifier que le dénominateur ne s'annule pas.
diviser par x : seulement si x ≠ 0
x2 = x : diviser par x fait perdre la solution 0. Factoriser : x(x − 1) = 0.

Inégalités

a < b ⇔ a + c < b + c
Ajouter ne change pas le sens.
k > 0 : k a < k b    k < 0 : k a > k b
Multiplier par un négatif retourne l'inégalité (c'est encore le demi-tour).
0 < a < b ⇒ 1a > 1b
La fonction inverse est décroissante sur ]0 ; +∞[. Une fonction croissante conserve l'ordre, une décroissante l'inverse.

Valeur absolue

|a b| = |a| · |b|    |a + b| ≤ |a| + |b|
|x − a| = distance entre x et a. |x − 2| < 1 ⇔ 1 < x < 3.

Exponentielle et logarithme terminale

ea+b = ea · eb    e−a = 1ea    (ea)n = ena
Mêmes règles que les puissances. ex > 0 toujours.
ln(a b) = ln a + ln b    ln ab = ln a − ln b    ln(an) = n ln a
Pour a, b > 0. Le logarithme transforme les produits en sommes.
eln x = x (x > 0)    ln(ex) = x    ln 1 = 0    ln e = 1
ab = eb ln a : c'est ainsi qu'on étudie 2x ou xx.
ln(a + b) ≠ ln a + ln b
Rien à faire avec une somme à l'intérieur.

Trigonométrie

cos2 x + sin2 x = 1
Pythagore sur le cercle unité.
cos(a + b) = cos a cos b − sin a sin b    sin(a + b) = sin a cos b + cos a sin b
D'où cos 2a = cos2 a − sin2 a = 2cos2 a − 1 et sin 2a = 2 sin a cos a. Se retrouve avec ei(a+b) = eia eib.
cos(−x) = cos x    sin(−x) = −sin x    cos(π − x) = −cos x
Se lisent sur le cercle : symétries.

Sommes terminale

1 + 2 + … + n = n(n + 1)2
Écrire la somme à l'endroit et à l'envers, additionner : n fois (n + 1).
1 + q + q2 + … + qn = 1 − qn+11 − q   (q ≠ 1)
Multiplier par (1 − q) : tout se télescope.
(n + 1)! = (n + 1) · n!
Pour simplifier (n + 1)!n! = n + 1.

Complexes ℂ · maths expertes

i2 = −1    z · z̄ = |z|2 = a2 + b2
Pour z = a + ib. D'où 1z = z̄|z|2.
eiθ = cos θ + i sin θ    eiθ · eiφ = ei(θ+φ)
Multiplier par eiθ = tourner de θ. Par −1 = eiπ : le demi-tour.

Faire apparaître les gestes d'exercice

Les règles ne s'appliquent que si l'expression a la bonne forme. Le travail, c'est de la lui donner — sans changer sa valeur.

Écrire 1 sous une autre forme

1 + 1c = cc + 1c = c + 1c

1 = cc (même dénominateur), 1 = cos2 + sin2, 1 = e0, 1 = ln e.

Ajouter et retrancher la même chose

x2 + 6x = x2 + 6x + 9 − 9 = (x + 3)2 − 9

Forme canonique : on complète le carré. Aussi xx + 1 = x + 1 − 1x + 1 = 1 − 1x + 1.

Découper un nombre

25 = 24 + 1    992 = (100 − 1)2 = 9801    49 · 51 = (50 − 1)(50 + 1) = 2499

On choisit le découpage qui fait apparaître une puissance de 10, un facteur commun ou une identité.

Faire apparaître un facteur commun

2n+1 + 2n = 2n · 2 + 2n = 2n(2 + 1) = 3 · 2n

Aussi e2x − ex = ex(ex − 1), et x3 − x = x(x − 1)(x + 1).

Multiplier par la quantité conjuguée

1√2 − 1 = √2 + 1(√2 − 1)(√2 + 1) = √2 + 1

(a − b)(a + b) = a2 − b2 fait disparaître les racines. Même idée dans ℂ : multiplier par z̄.

Mettre en facteur le terme dominant

2x2 + xx2 − 3 = x2(2 + 1x)x2(1 − 3x2) → 2 quand x → +∞

Pour lever une forme indéterminée ∞/∞ ou ∞ − ∞.

Séparer une fraction pour télescoper

1n(n + 1) = 1n − 1n + 1

Dans une somme, tous les termes intermédiaires s'annulent deux à deux.

Passer à l'exponentielle ou au logarithme

xx = ex ln x    2n > 1000 ⇔ n ln 2 > ln 1000

Une inconnue en exposant descend grâce au ln.

Changer de variable

x4 − 5x2 + 4 = 0   avec X = x2 :   X2 − 5X + 4 = 0

Aussi X = ex pour e2x − 3ex + 2 = 0.

Racine évidente, puis factoriser

x3 − 1 : x = 1 annule, donc (x − 1)(x2 + x + 1)

Tester 0, 1, −1, 2 : une racine r donne le facteur (x − r).

Écrire un nombre en produit de facteurs premiers

84126 = 22 · 3 · 72 · 32 · 7 = 23

On voit tout de suite les facteurs communs.

Chaque geste ci-dessus deviendra un « pouvoir » dans Pas à Pas : on l'obtient après l'avoir fait à la main, pas à pas.
