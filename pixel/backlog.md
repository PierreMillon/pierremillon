# Pixel — backlog

Page d'essai pour l'iPhone de Pierre : un seul pixel physique allumé, et les
dimensions réellement disponibles (points CSS, pixels, zones de sécurité,
dvh / svh / lvh). Sert à dimensionner les autres projets.

Ce n'est **pas un jeu** (pas d'échec, pas de session rejouable) : seule la
partie technique de la charte s'applique.

## Fait

- [x] v1 — pixel unique placé au doigt, cercle repère, cadre d'un pixel sur
  les bords, panneau des dimensions, historique

## Conformité à la charte (../REGLES-JEUX.md)

- Fait : écran figé (pas de défilement, zoom et loupe bloqués), mise à jour
  automatique (clés `pixel_*`), bouton Historique, fond noir / tracé vert
- Écarts : pas de PWA ni de service worker (inutile pour une page de mesure),
  pas d'anglais, rien à sauvegarder
- Pas dans le menu de `index.html` : page d'essai
